# 使用指南

工具究竟怎么用——README 里一句话带过的内容，在这里逐步展开。英文版见 [Usage](../en/usage.md)。

## 时间戳转日期时间

在 **01 · 双向转换** 左侧卡片中输入或粘贴时间戳：

1. 点击时间戳输入框并粘贴（如 `1760000000`）。
2. 结果立即出现在下方面板——没有提交按钮。
3. 可先选择单位：**自动**（默认）、**秒** 或 **毫秒**。

可接受的输入：

| 输入 | 解析为 | 说明 |
| --- | --- | --- |
| `1760000000`（不超过 11 位） | 秒 | |
| `1760000000000`（12–15 位） | 毫秒 | |
| `1760000000000000`（16 位及以上） | 微秒 | 内部换算为毫秒 |
| `-86400` | 负数（1970 年前） | 适用完整 ECMAScript 范围，约 ±273,790 年 |
| `1_760_000_000` / `1,760,000,000` / `1 760 000 000` | 容忍分隔符 | 解析前会剔除空格、逗号、下划线 |

单位按钮强制指定解释并覆盖位数自动识别——适用于边界附近有歧义的值（例如你确知某个 12 位数值是秒）。

错误显示在输入框下方，上一个有效结果保留在屏幕上——见表格[错误信息](#错误信息)。

## 日期时间转时间戳

使用 01 分区右侧卡片：

1. 用原生日期选择器选日期（公元 1 年起）。
2. 选时间——`HH:MM` 始终可用；秒位在支持的浏览器中可直接编辑，否则默认为 `0`（该输入框以 `step="1"` 渲染）。
3. 或点 **采用当前时间** 把当前时刻载入两个选择器后再调整。

解释始终基于你的**本地**时区；面板同时给出 UTC 等价值。

编辑任一卡片都会同步另一侧：输入时间戳会设置选择器，选择日期 / 时间会设置时间戳框（遵循当前单位选择）。

## 结果面板

对当前载入的时刻（你输入的，或页面打开时的「现在」），面板显示六行可复制内容：

| 行 | 格式 | 示例 |
| --- | --- | --- |
| 本地时间 | `YYYY-MM-DD HH:MM:SS · 星期` | `2025-10-09 09:33:20 · Thursday` |
| UTC 时间 | `YYYY-MM-DD HH:MM:SS UTC` | `2025-10-09 01:33:20 UTC` |
| ISO 8601 | 本地时间 + 数字偏移（毫秒非零时包含） | `2025-10-09T09:33:20+08:00` |
| Unix 秒 | 整数 | `1760000000` |
| Unix 毫秒 | 整数 | `1760000000000` |
| 相对现在 | 本地化、自动缩放单位 | `in 3 days` / `2 months ago` |

相对时间按 秒 → 分 → 时 → 天 → 年 逐级缩放（一年按 365.25 天计）；不足一秒显示「刚刚」。每行都有独立复制按钮。

## 实时当前时间

**02 · 当前时间** 分区始终处于活动状态：

- 本地日期与时间，以 250ms 节拍刷新（秒位不会显得过时），下方显示星期。
- 分区标题与页脚的时区标签显示你的 UTC 偏移与 IANA 时区名，例如 `GMT+08:00 · Asia/Shanghai`。
- 当前的 Unix **秒** / **毫秒** 值右侧各有复制按钮。
- 下方五张统计卡（自纪元起的天 / 周 / 月、年内第几天、ISO 周号）与结果面板使用同一套口径跟踪「现在」——见[纪元统计口径](#纪元统计口径)。

## 纪元统计口径

实时分区与结果面板都在**本地**日历日期上计算五个计数：

- **自 1970-01-01 第几天** —— 1970-01-01 本身是第 **1** 天（不是第 0 天）。
- **自 1970-01-01 第几周** —— 第 1 周覆盖 1970-01-01 ～ 01-07；从此锚点起每 7 天推进一周，与星期几无关。
- **自 1970-01-01 第几个月** —— 1970 年 1 月为第 1 月；`(年份 − 1970) × 12 + 月序`。
- **年内第几天** —— `NNN / 365`（闰年为 366）。
- **ISO 周号** —— 标准 ISO 8601 周号（周一为首、第 1 周含 1 月 4 日），旁边附 ISO 年份，用于 ISO 年与日历年不一致的日期。

注意 **「自 1970-01-01 第几周」与 ISO 周号是两个不同的计数**：前者是从纪元起不间断的 7 天分块，后者遵循日历周体系。两者都会显示。1970 年前的日期按设计产生非正计数。

## 复制按钮

每个值行（以及「现在」的两个时间戳）都有复制按钮；成功后图标变为对勾并停留 1.4 秒。复制路径在可用处走异步 Clipboard API，并在嵌入式 webview 或非安全上下文（异步 API 挂起或被拒）中自动回退到传统 `execCommand` 路径（与 800ms 超时竞速）。

## 语言

点击顶栏 **中文 / EN**。选择记入 localStorage（键 `ts-lang`），下次访问恢复。首次访问默认跟随浏览器语言（任何 `zh*` 区域 → 中文，否则英文）。在 localStorage 抛异常的隐私模式下，选择仅本次会话有效。所有内容即时重渲染，包括结果面板的星期与相对时间文案。

## URL 参数预填

追加 `?ts=<值>` 可预载转换器（解析与自动识别规则同手动输入）：

```
https://petrel2015.github.io/timestamp-tool/?ts=1760000000000
```

无效值会被忽略，页面以当前时间打开。

## 错误信息

| 情形 | 行为 |
| --- | --- |
| 非数字输入（`abc`、`1.5e9`、剔除分隔符后为空） | 输入框下方提示「请输入有效的数字时间戳」；上一个有效结果保留 |
| 数字但超范围（超出 ±273,790 年） | 提示「超出可表示的日期范围」；上一个有效结果保留 |
| 清空输入框 | 错误清除；「现在」的结果保留 |
| 有效输入 | 错误清除；六行结果 + 统计立即更新 |
| 二维码脚本加载失败（正常部署中不应发生） | 弹窗提示变为「二维码生成失败，请刷新重试」 |

反复出现的问题见[故障排查](./troubleshooting.md)。

## 边界行为

- **1970 年前：** 负数时间戳在时间戳框中可用；天 / 周 / 月计数按设计显示非正值。
- **公元 1 年前：** 只能经时间戳框到达（ECMAScript 范围约 ±273,790 年）；日期选择器无法到达。
- **微秒：** 16 位及以上数值被接受并按微秒处理（内部换算为毫秒）；面板本身始终只报秒与毫秒。
- **毫秒精度：** 仅当毫秒非零时，ISO 8601 行才包含 `.mmm`。
- **本地时间解释：** 日期 / 时间选择器始终指你的本地时区；没有时区选择器（明确的非目标——结果已含 UTC 与带偏移的 ISO）。

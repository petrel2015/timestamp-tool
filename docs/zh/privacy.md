# 隐私说明

本页每一项主张都对照源码核实过（三个 JS 文件、一个 HTML 文件——运行的东西仅此而已）。英文版见 [Privacy](../en/privacy.md)。

## 你的设备上存了什么

| 存储 | 键 | 值 | 生命周期 | 用途 |
| --- | --- | --- | --- | --- |
| localStorage | `ts-lang` | `zh` 或 `en` | 直到你清除站点数据 | 记住你的界面语言选择 |

这就是完整清单。没有 Cookie、没有 IndexedDB、没有 sessionStorage、没有缓存清单。

## 网络行为

- **核心功能零网络请求。** 所有转换、统计、格式化、剪贴板操作都是纯页面内 JavaScript；不向任何地址 fetch、post 或上报。页脚在 UI 中即声明了这一点。
- **一次延迟的本地脚本加载：** 首次打开赞赏弹窗时，页面加载 `vendor/qrcode-generator/qrcode.min.js`——一个 21 KB、**来自同一站点**的文件（提交在本仓库内）。不涉及任何第三方服务器。
- **仅在你明确点击时发生外部跳转：** 「打开支付宝」按钮（仅手机端）跳转到 `https://qr.alipay.com/…`。永远没有任何自动跳转。

以上你都可以自行验证：打开浏览器开发者工具的网络面板，把整个应用用一遍——日志保持为空，直到你打开赞赏弹窗（一条同源请求）或点击支付宝链接。

## 赞赏

- 二维码由浏览器从仓库中提交的支付串（`js/donation.js` 的 `DONATION_CONFIG`）**实时生成**。不下载任何二维码图片，也不调用任何支付 API。
- 你用支付 App 扫码后，一切支付行为完全发生在你与支付提供方（支付宝 / 微信）之间。本项目没有后端、收不到支付通知、不收集任何付款人数据。

## 不收集的东西

姓名、邮箱、标识符、使用统计、遥测、崩溃报告、位置——代码库中不存在任何一项。

## 本项目控制范围之外

- **托管：** 线上站点运行于 GitHub Pages；其服务器端访问日志由 GitHub 而非本项目管辖。
- **浏览器** 自身可能缓存页面的静态文件。
